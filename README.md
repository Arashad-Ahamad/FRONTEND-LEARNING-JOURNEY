## 🚀 Featured Projects

### 🟢 TaskFlow — Full-Stack Task Manager

**Tech:** Next.js 16 · TypeScript · Zod · Server Actions · Shadcn UI · Tailwind CSS

A CRUD task manager built with **Next.js Server Actions** — no separate API routes. Dual-side validation with Zod (client + server), React 19 `useActionState` for form state, and a custom stale-message fix.

- ⚡ Server Actions for add / toggle / delete (no `/api` routes)
- 🛡️ Dual-side validation with Zod + type inference
- ⏳ `useActionState` for loading & error states
- 🔄 Auto-reset form — success message auto-dismisses after 2s
- 🎨 Shadcn UI + Radix primitives

🔗 **[Live Demo](https://taskflow-arashad.vercel.app/)** · **[Source Code](./18-project/01-taskflow)**

---

### 🔵 DevBoard — Real-World Admin Dashboard

**Tech:** Next.js 16 · TypeScript · Redux Toolkit · Axios · Framer Motion · Shadcn UI

A responsive admin dashboard with collapsible sidebar, dark/light theme toggle, data tables with search/sort/pagination, and smooth animations.

- 📊 Dashboard with stat cards + charts
- 📦 Products page — search, sort, pagination via `useMemo`
- 🛒 Orders + Users pages with status/role badges
- 🔀 Collapsible sidebar with Framer Motion
- 🌗 Theme toggle with localStorage hydration (no flicker)
- 🔒 Type-safe Redux slices & API responses (FakeStore API)

🔗 **[Live Demo](https://devboard-arashad.vercel.app/)** · **[Source Code](./18-project/02-devboard)**
