# Arashad Ahamad — Portfolio

 **Live:** [arashad.vercel.app](https://arashad.vercel.app/)

A modern, responsive personal portfolio built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Shadcn UI**. Features a dark-first design, smooth scroll navigation, and a clean showcase of projects and experience.

---

##  Features

-  **Dark-first design** with light mode toggle (next-themes)
-  **Fully responsive** — mobile, tablet, desktop
-  **Next.js 16 App Router** with Server Components where possible
-  **Framer Motion animations** — subtle, not flashy
-  **Image optimization** with `next/image`
-  **SEO optimized** — metadata, OpenGraph, Twitter cards
-  **Accessible** — semantic HTML, ARIA labels, keyboard navigation
-  **Dynamic OG image** — generated with `next/og`
-  **Modular components** — Hero, About, Skills, Projects, Experience, Certifications, Contact
-  **Type-safe** — TypeScript interfaces for all data

---

##  Tech Stack

| Technology | Purpose |
